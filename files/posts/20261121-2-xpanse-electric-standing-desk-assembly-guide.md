> <strong>이 글의 위치</strong>: 집에서 작업과 공부를 겸할 수 있는 컴팩트한 전동 책상을 찾다가 <strong>Xpanse 전동 모션데스크(1200×600mm, 화이트)</strong>를 직접 구매해 조립했습니다. 이 글은 배송·개봉부터 나사 분류, 구동축(`E`)과 수평 맞추기(`L1=L2`) 중심의 실사 조립 순서, 그리고 영문 매뉴얼로만 제공되는 핸드 컨트롤러 설정법까지 한국어로 정리한 실전 기록입니다.

> <strong>3줄 요약</strong>
>
> 1. <strong>조립 난이도</strong>: 부품과 나사(`M-A`\~`M-F`)가 라벨별 비닐에 깔끔하게 나뉘어 있고 상판 하부에 타공이 되어 있어 혼자서도 차근차근 조립할 수 있습니다.
> 2. <strong>가장 중요한 2가지</strong>: 구동축(`E`)을 끼우기 전에 좌우 다리 높이(`L1=L2`)를 먼저 맞추고, 프레임 결합 후에는 동봉된 작은 육각렌치(`M-F-S`)로 <strong>`M-A` 무두 볼트</strong>를 반드시 조여야 좌우가 헛돌지 않습니다.
> 3. <strong>컨트롤러 활용</strong>: 4개 높이 메모리(`S-1`\~`S-4`)뿐 아니라 아이 안전을 위한 <strong>차일드락(`Loc`, ∧+∨ 5초)</strong>, 오류 시 <strong>리셋(`rSt`)</strong>, 충돌 방지 감도 설정까지 지원합니다.

## 🔧 4. 실제 조립 순서와 주의할 포인트

조립 자체는 순서만 지키면 어렵지 않지만, <strong>모터가 한쪽 다리에만 있는 싱글 모터(구동축 연동) 방식</strong>이라 초반 수평 맞추기와 구동축 고정이 핵심입니다.

### ① 양쪽 다리 높이(`L1=L2`) 맞추기 및 구동축 연결

모터가 달린 다리(`A`)와 반대쪽 다리(`B`)의 초기 길이가 미세하게 다를 수 있습니다. 구동축(`E`)을 반대쪽 다리에 꽂고 손으로 돌려 <strong>양쪽 다리 높이(`L1=L2`)를 똑같이 맞춘 뒤</strong> 조립을 시작해야 책상이 기울지 않습니다.

### ② 다리 하단과 발(`C`) 결합 (`M-C` × 8)

다리 끝의 흰색 가이드 돌기(핀) 2개에 발(`C`) 구멍을 맞춰 끼운 뒤, <strong>`M-C` 볼트 4개씩(총 8개)</strong>을 대각선 순서로 번갈아 조입니다. 한쪽을 먼저 꽉 조이면 수평이 틀어질 수 있으니 조금씩 번갈아 조이는 편이 좋습니다.

### ③ 크로스바(`D`) · 측면 브라켓(`F`) · 완충 패드(`P`) 부착

크로스바(`D`)를 `M-B` 볼트 4개로 다리 상단에 고정하고, 상판을 받치는 양쪽 측면 지지 브라켓(`F`)을 <strong>`M-E` 나사 4개</strong>로 체결합니다. 브라켓과 크로스바 위에는 동봉된 <strong>검정 완충 패드(`P`)</strong>를 붙여 상판과의 마찰·소음을 줄여 줍니다.

### ④ 구동축 `M-A` 무두 볼트 고정 (가장 많이 빠뜨리는 단계)

조립 중 제일 신경 써야 하는 부분입니다. 구동축 검은색 슬리브의 작은 구멍에 <strong>`M-A`(M4×4) 무두 볼트</strong>를 넣고, 동봉된 <strong>작은 `M2` 육각렌치(`M-F-S`)</strong>로 단단히 조여야 합니다. 이걸 빠뜨리면 모터 쪽 다리만 오르내리고 반대쪽 다리가 움직이지 않을 수 있습니다.

바닥에 상판을 뒤집어 놓고 조립된 프레임을 올린 뒤, 타공 위치에 맞춰 <strong>`M-D` 나사 10개</strong>로 고정합니다. 이어서 핸드 컨트롤러(`G`), 컵홀더(`M`), 헤드폰 걸이(`N`)를 원하는 쪽에 `M-D` 나사로 달고 케이블 클립(`O`)으로 전선을 정리하면 끝입니다.

## 🎮 5. 핸드 컨트롤러 사용법 & 설정 메뉴 정리

동봉된 컨트롤러 매뉴얼이 영문으로만 되어 있어, 실사용 시 자주 쓰는 조작법과 오류/설정 코드를 한국어로 정리했습니다.

| 기능 | 조작 방법 | 표시 및 참고 |
| :--- | :--- | :--- |
| <strong>높이 올리기 / 내리기</strong> | `∧` 또는 `∨` 버튼을 누르고 유지 | 상한/하한 도달 시 자동 정지 |
| <strong>메모리 높이 저장 (1\~4)</strong> | 원하는 높이에서 숫자 `1`\~`4` 중 하나를 <strong>3초간 길게</strong> 누름 | 디스플레이에 <strong>`S-1`</strong> 표시 후 저장 완료 |
| <strong>메모리 높이 호출</strong> | 저장된 `1`\~`4` 버튼을 <strong>짧게</strong> 누름 | 저장된 높이로 자동 이동 |
| <strong>책상 리셋(초기화)</strong> | `Er1`이 뜨거나 최저점에서 <strong>`∨`를 3초 이상</strong> 길게 누름 | <strong>`rSt`</strong> 표시 후 손 떼고 다시 `∨`를 길게 누르면 하강·반동 후 최저 높이로 초기화 |
| <strong>차일드락 (잠금/해제)</strong> | <strong>`∧` + `∨` 동시 5초 이상</strong> 길게 누름 | <strong>`Loc`</strong> 표시 시 버튼 잠금 (동일 동작으로 해제) |
| <strong>과열 보호</strong> | 짧은 시간 반복 승하강 시 자동 작동 | <strong>`Hot`</strong> 표시, 모터 보호를 위해 <strong>약 18분간</strong> 작동 제한 |
| <strong>모터 이상 경고</strong> | 모터·컨트롤러 신호 이상 시 발생 | <strong>`Er1`</strong> 표시, 전원 차단 후 케이블 연결 확인 및 리셋 진행 |

> <strong>상세 설정 메뉴 진입 (`1` + `2` 버튼 동시 20초 이상)</strong>
>
> 설정 메뉴에서는 `1` 또는 `2`를 짧게 눌러 1\~7번 항목을 이동하고, `∧`/`∨`로 값을 바꾼 뒤 <strong>`1` + `2`를 5초 이상</strong> 눌러 <strong>`888`</strong>이 뜨면 저장됩니다.
> - <strong>1번 / 2번</strong>: 하한 높이 / 상한 높이 설정 (`1cm` 단위, 상·하한 간 최소 `10cm` 이상 차이 필요)
> - <strong>3번</strong>: 기준 높이 보정 (`0\~30cm`)
> - <strong>4번 / 5번</strong>: 상승(`U-0`\~`U-9`) · 하강(`d-0`\~`d-9`) 충돌 방지 감도 (`0`은 끄기, `9`가 가장 민감)
> - <strong>6번 / 7번</strong>: 소수점 표시(`F-0` 끔 / `F-1` 켬), 단위 전환(`L-0` cm / `L-1` inch)

## ❓ 7. 자주 묻는 질문(FAQ)

### 혼자서 조립할 수 있나요?
가능합니다. 다만 상판과 하부 프레임을 결합한 뒤 최종적으로 뒤집어 바로 세우는 과정에서는 무게가 꽤 나가므로, 가능하면 두 사람이 함께 뒤집거나 주변 가구에 부딪히지 않게 공간을 넓게 비우고 작업하는 편이 안전합니다.

### 한쪽 다리만 움직이거나 높이가 어긋나면 어떻게 하나요?
구동축(`E`)이 반대쪽 다리 안쪽 육각 홈에 끝까지 들어갔는지, 그리고 <strong>`M-A` 무두 볼트</strong>가 작은 육각렌치(`M-F-S`)로 단단히 조여졌는지 확인하세요. 그다음 컨트롤러에서 <strong>`rSt` 리셋</strong>(최저점에서 `∨` 3초 유지 → `rSt` 표시 후 다시 `∨` 길게)을 실행하면 기준점이 다시 잡힙니다.

### 아이가 있는 집에서 버튼을 잘못 누르면 위험하지 않나요?
핸드 컨트롤러의 <strong>`∧` + `∨` 버튼을 동시에 5초 이상</strong> 누르면 <strong>`Loc`(차일드락)</strong>이 걸려 모든 버튼 입력이 차단됩니다. 같은 방식으로 5초 이상 누르면 다시 해제됩니다.
